# CV Craft 🚀

## AI-Powered Resume Builder

CV Craft is a modern resume-building platform that helps users create professional, ATS-friendly resumes with AI-powered optimization, customizable templates, and easy sharing options.

Build your resume, improve your content, and create a strong career profile — all in one place.

## ✨ Features

- 📝 **AI Resume Builder**  
  Create professional resumes with an easy-to-use editor.

- 🎨 **Modern Templates**  
  Choose from multiple resume templates designed for different career needs.

- 🤖 **AI Optimization**  
  Get suggestions to improve resume content and highlight your skills.

- 📂 **Resume Management**  
  Create, edit, save, and manage multiple resumes.

- 📄 **Download & Share**  
  Export resumes as PDFs and share them using live resume links.

- 🔐 **User Authentication**  
  Secure account management for personalized resume storage.
